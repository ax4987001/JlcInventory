# 嘉立创库存计价器 (JlcInventory)

**嘉立创库存计价器** 是一款专为硬件工程师、电子爱好者及小微企业设计的本地元器件库存管理与 BOM 计价辅助工具。它可以帮助你轻松管理本地库存，并与嘉立创或标准 EDA BOM 报价单进行深度比对，精确计算使用本地库存所能节省的真实成本，从而实现一键智能扣除与出库。

## ✨ 核心功能特性与进阶技巧

### 1. 智能 BOM 比对与计价
导入嘉立创或 EDA 导出的标准/非标准 BOM 表单，软件将自动与本地库存进行高精度比对。
* **状态高亮与置顶排序**：对比结果会严格按状态进行高亮（绿行：库存充足且划算；黄行：库存充足但单价较贵；红行：库存不足），并且程序会自动将绿色状态行置顶排序，让你优先关注“完全可使用本地库存解决”的元器件。
* **0 价格/无价格 BOM 适配**：对于纯 EDA 导出、没有附带 JLC 价格的 BOM（单价和总价均为 0），程序只要检测到本地库存满足数量需求，就会无条件将其判定为“绿行”（充足划算），极大地提升了泛用性。
* **底部悬浮智能统计窗**：当你勾选列表中的元器件时，底栏会实时计算出三个关键指标：
  - **原总价**：勾选项在原 BOM 上的总价；
  - **本地可替代真实需求总价**：使用本地库存所替换掉的 JLC 购买金额（真实为你省下的钱）；
  - **本次库存扣除总价**：按照本地购入成本计算出的本次消耗资金。

### 2. 灵活的库存管理与高容错导入
* **无缝兼容各类 Excel（高容错性）**：不需要严格遵循特定的表头规范！无论是标准 BOM，还是仅包含简陋列名（甚至没有表头）的非标准表格，引擎都会尝试基于“购买数量”、“库存”、“Quantity”、“所需数量”的优先级自动抓取数值。
* **二次确认与拦截面板**：在导入任何格式的表格时，都会弹出全局风格一致的二次确认拦截面板，支持勾选/反选，让你在最终入库前轻松剔除不需要导入的杂项。
* **智能加权平均成本**：当你分多次、以不同价格购入同一款元器件（同型号、同封装）时，系统会自动利用加权平均算法（`((旧库存量*旧单价) + (新入库量*新单价)) / (旧库存量+新入库量)`）自动更新并摊平你的库存成本，确保计价绝对准确。
* **单项/文本批量极速导入**：支持直接粘贴如“贴片电阻 0805 10k 100个 0.05元”的口语化/散乱文本，系统基于正则表达式进行词法分析，自动拆分出类目、型号、封装、数量并填充。

### 3. 一键出库与安全校验
* **一键勾选出库**：支持将比对完成的 BOM 勾选项一键从本地库存中扣除。
* **多项不足一次性汇总**：如果在扣除结算时发现有多个元器件的库存不足，系统不会像传统软件一样遇到第一个报错就阻断并让你重新排查，而是会将所有库存不足的项收集起来，在最后的自定义弹窗中一次性完整列出。
* **零库存安全过滤**：如果你勾选了本地未收录（0 库存）的项，出库引擎会自动静默过滤这些项，不会引发异常报错，确保整个结算流程顺畅。
* **一键导出本地库存**：支持将当前的本地库存一键导出为标准 Excel（兼容嘉立创格式），方便随时进行线下盘点。

### 4. Git 风格操作日志与快照级安全回退
* **高精度 Diff 日志记录**：每一次入库、扣除、修改或批量操作，都会在底层生成类似 Git diff 风格的详细日志。日志以不同颜色直观展示具体发生了什么：
  - `<span style="color:green">+</span>` 绿色代表新增入库
  - `<span style="color:red">-</span>` 红色代表库存消耗扣除
  - `<span style="color:yellow">~</span>` 黄色代表数据发生修改（如数量、价格的变化过程）
* **数据库级快照回退**：如果在大量导入或一键结算后发现操作失误（如导错了表格），可以在日志面板找到对应操作记录，点击“回退至此状态”。系统会直接利用该操作前的数据库 JSON 快照，实现瞬间安全回滚。

## 🛠️ 技术架构

* **前端交互**：HTML5 + CSS3 + Vanilla JS，深度定制的现代 UI，采用高 Z-Index 堆叠上下文管理的无扰动自定义全局弹窗（彻底弃用原生 `alert/confirm`）。
* **后端引擎**：C# .NET 8 (WinForms + WebView2)，以确保高性能的底层 Excel 读写、正则匹配与内存驻留。
* **持久化**：SQLite 嵌入式轻量级数据库，所有数据及快照均完全保存在本地磁盘，隐私安全零泄漏。
* **配置分离**：安装后，配置文件与程序分离。支持将 `.db` 数据库指定到非系统盘（如 D 盘或文档目录），系统重装数据无忧。

## 📦 安装与使用

1. 前往 `build` 文件夹或 Releases 页面下载最新版的独立安装包 `嘉立创库存计价器_v1.0.x.exe`。
2. 双击运行安装程序，安装时可自定义 **软件安装目录** 以及 **数据存储目录**（强烈推荐将数据存放在 D 盘或非系统盘）。
3. 安装完成后，在桌面双击带有“价”字专属图标的快捷方式即可开始管理你的元器件仓库！
